What is CVfacile?

CVfacile is a free, open-source command-line tool that builds one-page PDF résumés, typeset with LaTeX, from a single JSON file. It needs Python 3.8+ and nothing else.

Who it is for
Job seekers who want a different CV for each job offer, with an AI coding agent like Claude Code, Cursor or Codex, or by hand.
How it works
Your agent turns your old CV into cv.json, runs check and build, reads the warnings, and shortens the text until it fits on one page.
What you get
A PDF and a PNG preview, in 10 templates and every language you add. The CVs you generate are yours.

Your old CV in. A tailored one out.

Your agent does the rewriting. CVfacile does the layout, so every version looks right.

  1. Hand it overPoint your agent to your old PDF or Word file, or paste your LinkedIn profile.
  2. It writes cv.jsonOnly with what is in your CV: no invented jobs, degrees or numbers. If something is missing, it asks you.
  3. It builds and checksPDF and PNG preview. It reads the warnings and shortens the text until it fits on one page.
  4. One per offerPaste a job offer: it saves a variant for that offer. Your base CV does not change.

Works with Claude Code, Cursor and Codex. The repository ships the MCP tools (.mcp.json), --json output on every command, and the rules in AGENTS.md.

10 LaTeX templates. Same content.

Every résumé template works with the same JSON file. Switch with --template <name>, or compare them all with --template all. Click one to see it full size.

One JSON file. Every version.

One version per job offer, per language, with or without your phone number. Your agent keeps them all in the same JSON file.

Every language.
Every variant.

Any text or list can hold several languages. Variants patch the base CV: objects are merged, lists replaced, hide removes fields.

"label": {
  "en": "Full-Stack Engineer",
  "fr": "Développeur Full-Stack"
},
"variants": {
  "no-phone": { "hide": ["phone"] }
}

$ ./cvfacile build cv.json --lang fr --variant no-phone

Fits on one page

Slightly too long? The text drops from 10pt to 9pt and you are told. Still too long? You get a warning.

No LaTeX to write

Use **bold** and [links](https://…). Characters like &, % or _ are escaped for you.

Light to install

Python 3.8+, nothing else. No LaTeX? ./cvfacile setup installs Tectonic locally, without admin rights.

Autocomplete

A JSON Schema gives you autocompletion in VS Code. check points to the exact field of each error.

Get started in a minute.

Clone the repository, open your AI agent in the folder, and give it your old CV. Prefer doing it by hand? These commands are all you need.

$ git clone https://github.com/nem95/CVFacile.git && cd CVFacile
$ ./cvfacile doctor          # check LaTeX and image tools
$ ./cvfacile setup           # only if no LaTeX was found
$ ./cvfacile init mycv.json  # example CV to fill in
$ ./cvfacile build mycv.json

# French version, no phone, every template
$ ./cvfacile build mycv.json --lang fr --hide phone --template all

With Tectonic, the first build downloads the LaTeX packages it needs (about 2 minutes), then each build takes a few seconds. Every option is in the README.

Frequently asked questions.

How do I tailor my CV to a job offer with Claude Code?

Clone the repository and open Claude Code (or Cursor, or Codex) in the folder: .mcp.json gives the agent the CVfacile tools. Give it your old CV, then paste the job offer and ask for a variant. It saves the changes under a name like offer-x and builds the PDF.

Is CVfacile free?

Yes. CVfacile is free and open source under the AGPL-3.0, including for writing your own CV for work. A commercial license is only needed to build it into a product or a SaaS without publishing your code.

Do I need LaTeX installed?

No. ./cvfacile setup installs Tectonic into ./.bin, without admin rights. If pdflatex (TeX Live, MiKTeX) or the texlive/texlive Docker image is already there, CVfacile uses it.

Will the AI agent invent experience?

AGENTS.md tells agents to use only what you provided: no invented experience, degrees, numbers or skills. When something is missing, the agent asks you.

Can one CV have several languages and versions?

Yes. Any text or list can hold several languages, like {"en": "…", "fr": "…"}. Variants patch the base CV. Build one with --lang fr --variant offer-x, or hide fields with --hide phone,photo.

Is it ATS-friendly?

Yes, all 10 templates are ATS-friendly. The classic template is the most optimized: single column, no photo. Pick it when you apply through an applicant tracking system.

Does CVfacile send my CV anywhere?

No. CVfacile runs on your computer, with no server and no account. It only goes online to install Tectonic, which then downloads LaTeX packages. Your AI agent's provider sees what you share with the agent.

Who owns the CVs I generate?

You do. The license does not apply to their content.
